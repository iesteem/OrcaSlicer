# 高级速度 - 挤出速率平滑（Extrusion Rate Smoothing）

挤出速率平滑（ERS）（PrusaSlicer 中称为压力均衡器）旨在**将挤出体积变化速率限制在用户设定的阈值（ERS 值）以下**。
它用于辅助打印机固件内部的运动规划器和压力推进，实现理想的喷嘴流量，并减少相对理想流量的偏差。

其原理是减少挤出系统承受的压力冲击，同时减少压力推进平滑时间造成的相对理想挤出流量的绝对偏差。

此功能在高加速度、大流量打印时尤其有帮助，因为这些情况下偏差更大。

## 原理

启用此功能会在挤出流量需求突变的位置（如悬垂和悬垂轮廓）之前和之后减速再加速，形成一段小的**速度"坡道"**。

其工作方式是将打印的线段按 ERS 段长度分解为更小的"块"，并降低这些块的打印速度，使**请求的挤出体积流量变化小于等于 ERS 阈值**。

概括而言，**它"削平"了由加/减速引起的快速挤出变化，因为这些变化被分散到更长的距离和时间上。** 因此，它可以减少打印速度突变时出现的墙伪影。这些伪影的产生，是因为挤出机和固件无法完美跟随切片器请求的流量，尤其是在挤出速率快速变化时。

**下面的例子展示了被 ERS 缓解的伪影。**

![ers-artefact](https://github.com/SoftFever/OrcaSlicer/blob/main/doc/images/ERS/ers-artefact.jpg?raw=true)

上图可见的凸起，是由于挤出机在高加速度、高速度打印并被要求为悬垂减速时，无法足够快地响应所需的速度变化。

在上述场景中，打印机（Bambu Lab X1 Carbon）被要求以 5k/sec² 的加速度从 200mm/sec 减速到 40mm/sec。**挤出机跟不上压力变化，导致速度变化点前方出现轻微凸起。**

此参数与以下打印机运动学设置和物理限制相互作用：

1. **挤出机系统的能力** - 它能多快地改变喷嘴内的压力
2. **所配置的压力推进值** - 同样影响喷嘴内的压力变化
3. **打印机的加速度特性** - 加速度越高意味着压力变化越大
4. **压力推进平滑时间（Klipper）** - 平滑时间越长，相对理想挤出的偏差越大，此功能也就越有用

### 加速度与挤出速率平滑

打印机的运动系统并不完全遵循 OrcaSlicer G-code 预览界面中显示的速度变化。

当请求速度变化时，固件的前瞻规划器会计算达到目标速度所需的减速。减速速率受移动的加速度值限制。

**来看一个例子。** 假设以 **2k 外墙加速度**打印悬垂墙，打印机需要从 **200mm/sec 减速到 40mm/sec**。

这个减速移动将发生在约 9.6mm 的距离内，由以下公式得出：

```math
d = \frac{v_f^2 - v_i^2}{2a}
```

其中：

- vf = 末速度。
- vi = 初速度。
- a = 加速度（此处为负值，因为是减速）。
- d = 距离。

减速到新速度所需的时间约为 0.08 秒，由以下公式得出：

```math
t = \frac{v_f - v_i}{a}
```

打印机以 200mm/sec、0.42 线宽、0.16 层高打印时，挤出塑料的流量约为 12.16mm³/sec，如下图所示。

![ers-printspeed](https://github.com/SoftFever/OrcaSlicer/blob/main/doc/images/ERS/ers-printspeed.png?raw=true)

当打印机以 40mm/sec 挤出且线宽层高相同时，流量为 2.43mm³/sec。

因此，在这个例子中，我们要求挤出机**在 0.08 秒内从 12.16mm³/sec 的流量降到 2.43mm³/sec**，即挤出变化率为 121mm³/sec²。

**此值与打印机加速度成正比。4k 时翻倍，1k 时减半，且与移动速度或起止速度无关。**

**此值也与线宽成正比——线宽翻倍，挤出速率变化也翻倍，反之亦然。层高同理。**

继续这个例子，2k 加速度产生 121mm³/sec² 的挤出速率变化坡度。**因此，设置高于此值的 ERS 不会给打印质量带来任何收益，因为运动系统会根据其加速度设置以较缓的方式减速。**

**所以，加速度值是此设置的一个有意义的上限。** 本页后文提供了一组参考值。

### 压力推进与挤出速率平滑

接下来需要考虑压力推进和平滑时间这两个影响挤出速率的因素。

**压力推进（Pressure Advance）**通过调整挤出机速度来补偿热端熔区内的压力变化。当打印头移动并挤出耗材时，由于热端中熔融塑料的可压缩性，挤出齿轮的移动与塑料的实际挤出之间存在延迟。这种延迟可能导致打印头开始移动时挤出过多塑料，或停止时挤出不足，引发料点或欠挤出等问题。

**压力推进平滑时间**用于缓解压力推进算法控制的挤出流量快速变化可能对打印质量造成的负面影响。此参数本质上为压力推进所做的调整增加平滑效果，以避免挤出速率的剧烈或突然变化。

当压力推进调整挤出机速度以补偿热端内压力的建立或释放时，可能导致流量的突变。这些突变可能引发如下问题：

1. 挤出电机丢步，
2. 挤出齿轮和耗材磨损加剧，
3. 因挤出不均匀导致打印表面出现可见伪影。

平滑时间设置引入一个受控的延时，压力推进的调整被分散到这段时间内。这使得挤出压力的施加或释放更渐进，耗材流动的过渡更平滑。

代价是挤出精度。由于这种平滑，请求挤出量与实际挤出量之间存在偏差。

**1. 增大平滑时间：** 使挤出压力变化更渐进。虽然这可以减少伪影和对挤出系统的冲击，但设置过高会削弱压力推进的效果，因为补偿来得太迟，无法准确对抗压力动态。

**2. 减小平滑时间：** 使压力推进的调整更即时，可以改善压力补偿的响应性，但也可能重新引入流量突变，可能导致上述问题。

本质上，**压力推进平滑时间造成了相对理想挤出机转动（即挤出量）的有意偏差**，以使打印机挤出机在其机械限度内工作。此值通常设为 0.04 秒，意味着当压力推进调整挤出机流量以补偿热端压力变化时，这些调整被分散到 0.04 秒的时间内。

[这篇 Klipper 论坛帖子](https://klipper.discourse.group/t/pressure-advance-smooth-time-skews-pressure-advance/13451)中有压力推进平滑时间引起偏差的绝佳例子，值得一读以更深入理解这一权衡。

在上面的例子中，**我们需要设置一个足够低的挤出速率平滑值，以降低压力推进平滑时间对实际输出流量引入的误差。** 挤出速率平滑值越低，流量随时间的变化越小，由平滑时间算法造成的相对理想挤出的绝对偏差也越小。但过低的值会导致整体打印速度明显下降，因为打印速度会被大幅降低以在特征之间实现低挤出偏差，超过某个点后就没有实际收益了。

**找到有益下限的最好方法是实验。** 打印一个因悬垂打印速度设置而减速的尖锐悬垂物体，观察挤出不一致现象。

## 寻找理想的挤出速率平滑值

**首先，此值必须低于打印机加速度特性所产生的挤出速率变化。** 由于影响最大的通常是外墙表面质量，可使用外墙加速度作为参考基准。

**以下为 0.42 线宽、0.16 层高的一些近似 ERS 值。**

1. 0.5k 加速度对应 30mm³/sec
2. 1k 加速度对应 60.5mm³/sec
3. 2k 加速度对应 121mm³/sec²
4. 4k 加速度对应 242mm³/sec²

**以下为 0.42 线宽、0.20 层高的一些近似 ERS 值。**

1. 0.5k 加速度对应 38mm³/sec
2. 1k 加速度对应 76mm³/sec
3. 2k 加速度对应 150mm³/sec²
4. 4k 加速度对应 300mm³/sec²

**以下为 0.45 线宽、0.16 层高的一些近似 ERS 值。**

1. 0.5k 加速度对应 32mm³/sec
2. 1k 加速度对应 65mm³/sec
3. 2k 加速度对应 129mm³/sec²
4. 4k 加速度对应 260mm³/sec²

**因此，你的调校起点必须低于上述最大值的 ERS 值。** 一个好的测试打印起点是上述最大值的 **60-80%**。这能为压力推进提供有实际意义的辅助，减少压力推进平滑时间引入的偏差。平滑时间越大，质量收益越大。

因此，对于 **0.42 线宽、0.16 层高**，以下是推荐的 ERS 起始值：

1. 0.5k 加速度对应 18-25mm³/sec
2. 1k 加速度对应 35-50mm³/sec
3. 2k 加速度对应 70-100mm³/sec²
4. 4k 加速度对应 145-200mm³/sec²

若以 0.2 层高打印，可将这些值提高 25%；层高更低则相应减少。

**第二个因素是挤出机的机械能力。** 对耗材抓持良好的直驱挤出机通常对挤出速率变化响应更快。硬质耗材也是如此。相反，Bowden 打印机，或打印 TPU、polyterra 等较软材料时，由于机械抓持力、材料变形或压力传递延迟（Bowden 结构），挤出机更容易打滑或偏离所需挤出量。

**最后一个因素是压力推进平滑时间（或闭源固件中的等价物）引入的偏差。** 此值越大，相对理想挤出的偏差越大。若你使用直驱挤出机，请在调校 ERS 之前先将 Klipper 固件中的此值降到 0.02，因为更低的值意味着更小的待缓解偏差。然后再进行 ERS 的实验性调校。

**那么具体该怎么做？**

以上述 ERS 设置为起点进行测试打印，并按喜好调整！若在速度变化剧烈的尖锐悬垂处（如 Benchy 船体）发现凸起，将此值降低 10% 再试。

若没有发现伪影，可提高 10%，但不要超过上面推荐的最大值，否则此功能对你的打印将失去作用。

## 给使用无压力推进 Marlin 的 Bowden 打印机的说明

若你的打印机不支持压力推进，尤其是使用 Bowden 结构时，你无法享受压力推进动态调整流量的好处。

在这种特殊情况下，ERS 将承担通常由压力推进完成的全部工作。此场景下通常建议使用 8-10mm³/sec 的低值，且与加速度设置无关，以尽可能平滑挤出系统内的压力变化，同时不过多影响打印速度。

## 关于 ERS 段长度的说明

理想情况下，你希望将此值设为 1，以在每次速度过渡之间获得最多的台阶数。但这可能导致 G-code 过大，每秒发送到 MCU 的指令过多而使其跟不上。同时也会拖慢 OrcaSlicer 前端，因为切片模型更复杂、渲染更慢。

对于 Klipper 打印机，段长度设为 1 通常没问题，因为树莓派或类似设备有足够的计算能力处理 G-code 指令量。

同样，对于 Bambu Lab 打印机，段长度设为 1 效果良好。**但是，若你发现打印机卡顿或停滞**（算力较弱的 P1 系列打印机可能出现），或在 Klipper 中遇到 **"Timer too close" 错误**，**请将此值增加到 2 或 3**。这会削弱该设置的效果，但给打印机带来更可承受的负载。

## 局限性

**此功能只在切片器引发速度变化的地方起作用** —— 例如打印悬垂、桥时从快到慢打印移动的过渡，以及从内部特征到外部特征的切换，反之亦然。

但打印机因固件指令而减速时，它无法影响挤出机行为 —— 例如转过拐角时。

这种情况下，打印机独立于切片器的请求进行减速和加速。此时切片器下达的是恒定速度指令，但打印机在自行调整以在其运动学限度（SCV/Jerk）和加速度内运行。由于切片器不知道这种减速，它无法对该特征应用预判性的挤出速率平滑，变化完全由打印机固件支配。
