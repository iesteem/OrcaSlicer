# GUI 层用例（Use Cases）

> 状态：草案 v0.1（2026-09-09）——覆盖主干旅程，边角用例待增补。
> 按用户旅程组织（非代码模块）。每个用例含：入口、主流程、期望行为、验收锚点。
> 未标注 `[MUST]`/`[SHOULD]` 的条目默认为 `[CURRENT]`。

## UC-A 模型导入与准备

### A1 导入模型
- **入口**：菜单打开/拖拽文件/最近文件/双击文件关联（.stl/.3mf/.bbs_3mf/.obj/.step/.amf）
- **行为**：模型落入打印床中心偏移位置；多文件导入各自摆放；非法文件给出明确错误（P3）`[MUST]`
- **锚点**：分别导入 tests/data 各格式样例，观察落床位置与错误提示。STEP 导入耗时应有进度反馈 `[SHOULD]`

### A2 项目文件读写（L0 死锁）
- **行为**：保存/另存为 3MF；重开旧版本项目文件，物体、变换、多色分配、配置完整还原 `[MUST]`
- **锚点**：用历史版本（如 2.3.x）产出的 3MF 在新实现中打开，逐项比对。

### A3 物体操作
- **行为**：选择（点选/框选）、移动/旋转/缩放（手柄 + 数值输入）、复制/镜像/阵列、落地、填充打印床 `[MUST]`（语义：入口+手势→结果）
- 快捷键绑定属于 L1 `[MUST]`；手柄视觉样式属于 L2
- **锚点**：对每个变换执行手柄操作与精确数值两种路径，结果一致。

## UC-B 打印配置

### B1 打印参数设置
- **入口**：左侧参数面板，按 过程/打印机/耗材 分组
- **行为**：全部配置项可读写且即时生效；"已修改"标记与恢复默认可用 `[MUST]`；搜索/过滤参数 `[SHOULD]`
- **锚点**：修改任一参数 → 预设显示为已修改 → 差异视图列出该项 → 恢复默认后还原。

### B2 预设管理
- **行为**：系统预设只读；用户副本可建/改/删（删除需确认）；导入导出预设包 `[MUST]`；升级版本后用户预设完整保留（P1）`[MUST]`
- **锚点**：建用户预设 → 模拟版本升级 → 预设仍在且参数不变。

### B3 多耗材/多色
- **行为**：为物体/零件/局部（修饰罐）分配耗材；擦除塔启用条件与参数可配 `[MUST]`
- **锚点**：双耗材场景：物体着色 → 切片 → 预览中颜色分层与耗材映射一致（P2）。

### B4 机型切换
- **行为**：切换打印机机型后，配置体系整体迁移到新机型；不兼容参数显式提示而非静默重置（P1，对应历史修复"机型切换耗材保持"）`[MUST]`
- **锚点**：带用户耗材配置切换机型，确认提示出现且耗材设置按规则保留。

## UC-C 切片与预览

### C1 切片执行
- **行为**：后台线程执行，进度可见，可取消（P5）`[MUST]`；取消后状态一致可重新切片 `[MUST]`
- **锚点**：对复杂模型切片中途取消 → 修改参数 → 重新切片成功。

### C2 预览模式
- **行为**：切片后进入预览：层滑块、视图模式（线条/预览）、耗材着色、速度/流量/层高等信息着色 `[MUST]`（语义）
- **锚点**：与旧实现并排比对同一项目的预览着色语义（容许渲染细节差异）。

### C3 G-code 输出
- **行为**：导出到文件/可移动介质；相同输入配置产出语义相同的 G-code（L0）`[MUST]`
- **锚点**：diff 新旧实现的 G-code，差异需逐项归类为"已知的非语义差异"或缺陷。

## UC-D 机器交互（网络/发送）

### D1 机器连接与绑定
- **行为**：设备发现/绑定流程；绑定状态可视；解绑需确认且不残留脏数据 `[MUST]`；离线时本地功能全部可用（P4）`[MUST]`

### D2 发送打印任务
- **行为**：发送到机器（含 AMS 耗材映射）；发送进度可见、失败显式可重试（P3/P5）`[MUST]`
- **锚点**：映射弹窗中耗材对应关系与项目多色分配一致。

### D3 监控
- **行为**：打印机状态/摄像头画面（可用时）展示 `[CURRENT]`；打印控制（暂停/停止）需确认 `[MUST]`

## UC-E 校准流程

### E1 校准向导
- **入口**：校准面板（Flow/Dynamic Flow/Temp/PA/Max Vol/Passport 等向导）
- **行为**：向导分步推进（选择预设→参数→执行→保存结果）；校准历史可查 `[MUST]`（语义）；向导间风格统一属例外名单（宪章 §6）
- **锚点**：完整走一个 PA 校准向导，结果写入校准历史并可应用到耗材预设。

## UC-F 环境

### F1 首次启动与升级
- **行为**：首次启动引导（语言/向导）；版本升级触发配置迁移，迁移前提示，旧配置备份可回退（P1）`[MUST]`
- **锚点**：用旧版本配置目录启动新实现，确认迁移提示与回退路径。

### F2 语言与主题
- **行为**：语言切换即时生效且覆盖完整；明暗主题切换全局一致；高 DPI 下无布局破坏 `[MUST]`

### F3 崩溃恢复
- **行为**：异常退出后的自动备份恢复提示 `[SHOULD]`
